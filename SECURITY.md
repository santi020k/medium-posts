# Security policy

This repository contains educational snapshot code and is not supported as a
production application or a starter for new projects.

Report vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/santi020k/medium-posts/security/advisories/new).
Do not open a public issue for a vulnerability or include credentials in a
report.

Security fixes may update the examples where compatibility allows. Framework
major upgrades can require a new article-era branch rather than changing an
older example in place.
